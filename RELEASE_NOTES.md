# ReelsTT 0.0.100 — Preview

First public experimental Windows x64 release.

- Local folder library, video feed, favorites, search and sorting.
- Hardware accelerated libmpv playback with bounded preloading.
- Confirmed Recycle Bin deletion and local-only preferences/cache.
- Modern per-user Velopack setup with a compact splash, no legacy wizard.

Download `SUWS.ReelsTT-win-preview-Setup.exe` to install, or the portable ZIP.
The build is unsigned. RAM below 500 MB is a target, not a guarantee.
